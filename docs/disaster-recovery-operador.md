# Disaster recovery del operador — cuando algo falla

> **Contacto de emergencia**: <teléfono del administrador/soporte>.
> **Horario**: <horario>. **Respuesta esperada**: <tiempo>.

Cada caso: **síntoma → verificación rápida → acción → contacto**.

## 1. "No puedo entrar al sistema" (login falla)
- **Verificación (30s)**: ¿escribiste bien el correo y la clave? ¿Otro compañero
  puede entrar?
- **Acción**: recargá la página (F5) y volvé a intentar. Si tu clave está mal,
  pedí el reseteo.
- **Contacto**: admin.

## 2. "El mapa no carga" (geovisor en blanco)
- **Verificación**: esperá 10-15s; probá cambiar el mapa base a "Satélite".
- **Acción**: recargá la página. Probá otro navegador.
- **Contacto**: admin si sigue igual.

## 3. "El inicio muestra datos viejos"
- **Verificación**: mirá la fecha de las últimas aplicaciones.
- **Acción**: recargá la página (los datos se actualizan solos cada pocos minutos).
- **Contacto**: admin si pasan más de 24h.

## 4. "Registré una fumigación pero no aparece"
- **Verificación**: buscá la fumigación en "Fumigaciones" por la fecha.
- **Acción**: esperá unos segundos y recargá. Verificá que la registraste en la
  parcela correcta.
- **Contacto**: admin si desapareció de verdad.

## 5. "El dron no está subiendo vuelos"
- **Verificación**: ¿el dron estuvo en una zona con internet? ¿El piloto abrió
  SmartFarm?
- **Acción**: pedile al piloto que abra SmartFarm y sincronice. Esperá unos minutos.
- **Contacto**: admin si pasan horas.

## En todos los casos
1. **No borres ni repitas** la operación muchas veces.
2. Sacá una **foto de la pantalla** y mandásela al admin.
3. Anotá **qué hiciste** justo antes del problema.
