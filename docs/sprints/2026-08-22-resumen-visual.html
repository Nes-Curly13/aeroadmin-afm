3. Parcel drawer — fix bug de clicks (PR #6)

Root cause

draw.setMode("polygon") se ejecutaba antes de que el adapter de terra-draw disparara el callback ready. En esa ventana, el handler onClick del polygon mode no estaba montado — los clicks caían en un mapa "inerte".

Diagrama de secuencia — el fix

sequenceDiagram participant U as Operador participant M as MapLibre Map participant TD as TerraDraw participant A as Adapter MapLibre Note over M,A: Antes del fix — race condition M->>TD: start() TD->>A: register() (async setup) TD-->>TD: setMode("polygon") ← se ejecuta antes de onReady U->>M: click M->>A: pointer event A-->>U: nada (handler no montado aún) Note over M,A: Después del fix M->>TD: start() TD-->>TD: on("ready", cb) registrado TD->>A: register() (async setup) A-->>TD: onReady() TD->>TD: cb: doubleClickZoom.disable() + setMode("polygon") U->>M: click M->>A: pointer event A-->>U: vértice añadido al polígono ✓

Diff del fix

  map.on("load", () => {
    const draw = new TerraDraw({ adapter, modes });
    drawRef.current = draw;
-   draw.start();
-   draw.setMode("polygon");
-   draw.on("finish", () => { /* handler */ });
+   draw.on("ready", () => {
+     map.doubleClickZoom.disable();
+     draw.setMode("polygon");
+     draw.on("finish", () => { /* handler */ });
+   });
+   draw.start();
  });
