# 6. Reportes

Entrás desde el menú lateral, **"Reportes"**. Sirve para ver y descargar el
resumen de la operación.

## Filtros
- **Desde / Hasta**: el rango de fechas.
- **Hacienda**: una finca en particular, o todas.
- Atajos: **7d**, **30d**, **90d**, **Mes**, **Año**.

## Pestañas
- **Reporte operativo**: lista de fumigaciones del período (fecha, producto,
  parcela, área, volumen).
- **Resumen por parcela**: totales por cada suerte.

## Descargar (solo admin)
- **PDF**: reporte con formato para imprimir.
- **CSV**: para abrir en Excel.

> Si no sos admin, los botones de descarga aparecen deshabilitados.

## Si esto no funciona
- Si no aparecen datos, ampliá el rango de fechas o quitá el filtro de hacienda.
- Si el PDF/CSV no descarga, avisá al admin (puede ser un tema de permisos).
