# 5. Geovisor (mapa)

Es el mapa para ver todo de un vistazo. Entrás desde el menú lateral, **"Geovisor"**.

## Partes de la pantalla
- **Izquierda — Filtros**: búsqueda, rango de fechas (Desde / Hasta), capas
  (polígonos, aplicaciones, etiquetas) y mapa base (Satélite, Híbrido, Calles).
- **Centro — Mapa**: las parcelas y las aplicaciones del rango elegido.
- **Derecha — Lista de fumigaciones**: los eventos del período, ordenados del más
  nuevo al más viejo. Click en uno para verlo en el mapa.

## Qué podés hacer
1. Escribí en **Buscar** para encontrar una suerte, hacienda o variedad.
2. Ajustá **Desde** y **Hasta** para acotar el período.
3. Encendé/apagá **capas** según lo que quieras ver.
4. Cambiá el **mapa base** (Satélite suele verse mejor para el campo).
5. Click en una parcela o en una aplicación para ver el detalle.

## Datos que muestra
- **Fumigaciones**: cantidad en el rango.
- **Parcelas tratadas** y **Área aplicada**.
- **Última aplicación**.

## Si esto no funciona
- Si el mapa se ve gris, esperá unos segundos (las imágenes satelitales tardan).
- Si no aparecen parcelas, revisá que la capa "Polígonos de parcelas" esté encendida.
- Si la lista está vacía, ampliá el rango de fechas.
