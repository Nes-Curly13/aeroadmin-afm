# Manual del operador — AFM Geovisor

> **Audiencia**: operador fumigador del Valle del Cauca (NO es desarrollador).
> **Última actualización**: 2026-09-13.
> **Cómo se usa**: entrá por `00-indice.md`. Cada guía es independiente.

Este manual explica cómo usar el panel **AFM Geovisor** para consultar tus
parcelas, registrar fumigaciones, ver el mapa y sacar reportes.

> o la sección "Si esto no funciona" al final de cada guía.

## Qué NO hace este sistema
- No pilotea el dron (eso se hace con el control de DJI).
- No es la app de DJI SmartFarm.
- Solo **gestiona y visualiza** lo que ya pasó en el campo (o lo que registrás a mano).
